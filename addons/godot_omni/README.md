# Godot MCP Omni

The **Godot MCP Omni** editor plugin works alongside **Godot MCP Core**
(`addons/godot_ai`) to give AI assistants full control of the Godot editor via
the [Model Context Protocol](https://modelcontextprotocol.io/introduction).

- 1,820 canonical engine operations across 59 domains
- Arbitrary in-memory GDScript evaluation (`godot_eval`)
- Universal object reflection and editor UI automation
- Live tool-call monitor and interactive sandbox dock

## Enable

Project > Project Settings > Plugins > enable **Godot MCP Omni** (and **Godot MCP Core**).

## Requirements

- Godot 4.7 or newer
- Python 3.11–3.14 and `uvx` on the Godot machine (see the repository README)
